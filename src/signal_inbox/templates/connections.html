Set up “Save to Signal” in Apple Shortcuts
  1. Create a shortcut, enable Show in Share Sheet and accept URLs and Safari web pages.
  2. Add Get URLs from Input, using Shortcut Input, then Repeat with Each URL.
  3. Inside the repeat, add Get Contents of URL with {{ capture_endpoint }} and method POST.
  4. Add the Authorization header with Bearer YOUR_TOKEN. Replace YOUR_TOKEN with the token above.
  5. Set Request Body to JSON. Add a text field named url and select Repeat Item as its value.
  6. Read source.id from the response before showing success. If absent, show detail as an error. When created is true, show “Saved to Inbox”; otherwise show “Already saved”.

The token belongs only in the request header. Remove it before sharing your shortcut with anyone else.
